# TinyML AI Model for Offline Water Quality Prediction

This repository presents an end-to-end workflow for developing and deploying a TinyML-compatible AI model for offline water quality prediction. The project focuses on creating a lightweight neural network that can classify water quality into "Good," "Moderate," or "Poor" categories based on various sensor readings. The model is designed to be easily embedded into resource-constrained devices, enabling real-time, on-device inference without constant connectivity.

## Project Overview

The core idea behind this project is to provide a predictive model for water quality suitable for edge computing scenarios. It includes scripts for:
1.  Generating synthetic water quality data for training purposes.
2.  Training a compact TensorFlow neural network.
3.  Converting the trained model into a TensorFlow Lite format for efficiency.
4.  Transforming the TensorFlow Lite model into a C++ byte array, making it ready for integration into embedded systems using TensorFlow Lite Micro.

This setup is ideal for applications like smart agriculture, environmental monitoring, or remote sensing where power efficiency and offline capabilities are crucial.

## Project Structure and Components

The repository is organized into several key files, each serving a specific role in the model development and deployment pipeline:

*   **`.idea/`**: Contains configuration files for the IntelliJ IDEA IDE, relevant for development setup.
*   **`LICENSE`**: Defines the project's licensing terms, which is the MIT License.
*   **`generate_water_quality_data.py`**:
    *   A Python script responsible for creating a synthetic dataset (`water_quality_data.csv`) that simulates various water quality parameters.
    *   It generates realistic values for pH, Total Dissolved Solids (TDS), Turbidity, Water Temperature, Air Temperature, Humidity, and a 'Rain' binary indicator.
    *   Based on predefined conditions, it assigns a `Label` ("Good", "Moderate", or "Poor") to each sample.
*   **`water_quality_data.csv`**:
    *   The synthetic dataset generated by `generate_water_quality_data.py`.
    *   This CSV file serves as the input for training the AI model, containing the features and their corresponding water quality labels.
*   **`train_water_quality_model.py`**:
    *   This Python script handles the core machine learning pipeline.
    *   It loads the `water_quality_data.csv`, preprocesses the data (label encoding, train-test split, feature standardization).
    *   Builds and trains a small Keras Sequential model (neural network) for classification.
    *   Evaluates the model's accuracy on a test set.
    *   Crucially, it converts the trained Keras model into the TensorFlow Lite (`.tflite`) format, optimizing it for deployment on edge devices.
*   **`water_quality_model.tflite`**:
    *   The output of the `train_water_quality_model.py` script.
    *   This is the TensorFlow Lite model file, which is a highly optimized, compact representation of the neural network, ready for on-device inference.
*   **`convert_tflite_to_cpp.py`**:
    *   A Python script that takes the `water_quality_model.tflite` file and converts its binary content into a C++ byte array.
    *   This transformation allows the model to be directly embedded into C/C++ projects, typically for microcontrollers and other embedded systems using TensorFlow Lite Micro.
*   **`model_data.cpp`**:
    *   The C++ source file generated by `convert_tflite_to_cpp.py`.
    *   It contains the TensorFlow Lite model data as a `const unsigned char[]` array, along with its length (`g_water_quality_model_len`), making it directly usable within an embedded C/C++ application.

## Setup and Usage

To set up and run this project locally, follow these steps:

### Prerequisites

Ensure you have Python 3.x installed. The project relies on several Python libraries:

*   `pandas`
*   `numpy`
*   `tensorflow` (including TensorFlow Lite conversion tools)
*   `scikit-learn`

You can install these dependencies using pip:

```bash
pip install pandas numpy tensorflow scikit-learn
```

### Steps

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/sasikumar161106/Tinyml_AI_Model_For_Offline_Water_Quality_Prediction.git
    cd Tinyml_AI_Model_For_Offline_Water_Quality_Prediction
    ```

2.  **Generate the synthetic water quality dataset:**
    This script creates `water_quality_data.csv`.

    ```bash
    python generate_water_quality_data.py
    ```

3.  **Train the AI model and convert it to TFLite:**
    This script will train the neural network, evaluate its performance, and save the TensorFlow Lite model as `water_quality_model.tflite`.

    ```bash
    python train_water_quality_model.py
    ```

4.  **Convert the TFLite model to a C++ byte array:**
    This step generates `model_data.cpp`, which contains the model embedded as a C++ array.

    ```bash
    python convert_tflite_to_cpp.py
    ```

### Deployment (Conceptual)

The generated `model_data.cpp` file can then be included in your embedded C/C++ project. You would typically use the TensorFlow Lite Micro library to load and run this model on a microcontroller or other resource-constrained device.
